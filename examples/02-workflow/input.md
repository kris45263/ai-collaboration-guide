# 场景：开发速度、代码质量与流程开销

## 用户材料

我刚开始用 Claude 做一个 Electron 的 macOS 桌面应用。上周做界面只有两天交付时间，我试了几个 UI skills，对结果不满意，但还是得交付，代码质量就作了妥协，后面还要重构。

我也试过一套比较完整的技能流程，但简单任务问很多问题，又开子代理、审查和跑检查，过程慢了不少。我现在退回到手动教它，把一些要求放进 CLAUDE.md。接下来还要改进 prompts 和获取 AI insights 的 orchestrator。我想找一套适合我的协作方式，也想知道是不是应该换一些 skills。
